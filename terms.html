2. Educational Use & Local Guest Mode

JavaQst is designed for students, developers, and educators learning the Java programming language. Users may participate either by registering a cloud-synchronized account or through Local Guest Mode:

3. Safe Sandbox & Code Execution Policy

JavaQst provides a live in-browser compiler and runner powered by remote, isolated OpenJDK 22 Linux micro-containers. To maintain server stability and community safety, the following conditions apply:

  • Permitted Use: You may write, compile, and execute Java algorithms, data structures, Scanner CLI tools, and educational scripts covered within our curriculum.
  • Strictly Prohibited: You must not attempt denial-of-service (DoS) attacks, network port scanning, cryptocurrency mining, container escapes, excessive CPU/memory consumption loops, or deploying malicious payloads.
  • Resource Caps: Code execution is capped at a maximum of 15 seconds runtime and 256MB memory per process to ensure equitable resource distribution.
