About JavaQst

JavaQst is an open, modern learning experience created by Advaith M Joy. It is designed to take aspiring software developers and computer science students from basic programming principles to production-ready Java 21 LTS cloud development.

Our Mission

Traditional computer science education often forces students to read static textbooks and wrestle with complex command-line configurations before seeing their first program run. JavaQst changes this paradigm by gamifying curriculum progression with retro pixel-art mechanics, interactive milestone nodes, and a sandboxed OpenJDK 22/24 compiler directly in the browser.

Platform Highlights

  • 24 Comprehensive Modules: Divided into Overworld (Beginner), The Nether (Intermediate), and The End (Advanced), covering syntax, OOP, Streams, Concurrency, JUnit 5, and Spring Boot.
  • Native Cloud Sandbox: Every exercise executes against real OpenJDK compilers with instantaneous terminal feedback.
  • AI Companion "Meowger": Powered by Google Gemini, providing Socratic hints, code reviews, and explanations without spoiling solutions.
  • Play Store & Mobile Ready: Built as a high-performance Progressive Web App (PWA) with full offline shell caching and mobile responsiveness.
